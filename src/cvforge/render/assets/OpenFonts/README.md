# OpenFonts

Fonts bundled for `cover.cls` (cover letter, compiled with xelatex) and, for Lato,
the moderncv CV template (compiled with lualatex).
Copied unchanged from the upstream project ai-job-search (MIT),
`cover_letters/OpenFonts/`.

- `fonts/lato/`: Lato, tyPoland Lukasz Dziedzic. Licence: `fonts/lato/OFL.txt`.
- `fonts/raleway/`: Raleway, Matt McInerney, Pablo Impallari, Rodrigo Fuenzalida. Licence: `fonts/raleway/OFL.txt`.

Both are under the SIL Open Font License 1.1. The licence texts are the
official files from https://github.com/google/fonts (`ofl/lato/OFL.txt`,
`ofl/raleway/OFL.txt`) and must stay next to the fonts.
