# OpenFonts

Fonts bundled for `cover.cls` (cover letter, compiled with xelatex).
Copied unchanged from the upstream project ai-job-search (MIT),
`cover_letters/OpenFonts/`.

- `fonts/lato/`: Lato (Lukasz Dziedzic / tyPoland). SIL Open Font License 1.1.
- `fonts/raleway/`: Raleway (Matt McInerney, Pablo Impallari, Rodrigo Fuenzalida). SIL Open Font License 1.1.

Licence text: https://openfontlicense.org (SIL OFL 1.1). Note: the upstream
repository ships no separate OFL licence files for these fonts, so the
attribution above is taken from the fonts' public distribution (Google Fonts),
not from upstream files.
